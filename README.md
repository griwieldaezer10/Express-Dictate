## 📖 Overview
<a id="overview"></a>

**Express Dictate** is a professional multimedia digital dictation recorder designed for Windows. This powerful software allows you to effortlessly record dictations and send them directly to a typist, ensuring your workflow remains smooth and efficient. The **latest version** of Express Dictate is packed with all features for a full dictation experience, including voice-activated recording, encryption, and various modes for recording. Enjoy the convenience of seamless integration with the Express Delegate workflow manager for enhanced productivity.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Voice Activated Recording** — Automatically begins recording when you start speaking, ensuring you never miss an important dictation.
- **Variable Recording Modes** — Choose from overwrite, insert, or append modes to suit your dictation style.
- **Secure Encryption** — Protect your sensitive recordings with built-in encryption capabilities.
- **Multi-Channel Output** — Send dictations via email, FTP, LAN, or command line for versatile sharing options.
- **Handheld Device & Foot Pedal Control** — Control your dictation hands-free for maximum convenience and efficiency.
